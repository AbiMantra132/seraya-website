# Seraya Website

Seraya is a modern web platform built with Next.js dedicated to empowering Indonesian youth through education, innovation, and creative collaboration. 

The platform features:
- **Interactive Quizzes**: Engage users and help them find their role in social impact.
- **News & Articles**: Share inspiring stories and updates on youth collaborations.
- **Content Galleries**: Showcase creative portfolios and project highlights.
- **AI-Powered Chat**: Provide interactive assistance and guidance.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project is built using:
- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [GSAP](https://gsap.com/) for animations
- [Neon](https://neon.tech/) for serverless Postgres database
- [Google Generative AI](https://ai.google.dev/) / OpenAI for AI integrations
